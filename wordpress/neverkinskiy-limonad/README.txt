Неверкинский лимонад — тема WordPress 1.0.0

Установка: Внешний вид → Темы → Добавить → Загрузить тему → загрузить ZIP → Активировать.
Постоянные ссылки: выбрать «Название записи» и сохранить.
Редактирование основных текстов, контактов, 5 товаров и изображений: «НЛ — Контент».
Обычные страницы: «Страницы». Шорткод [nl_layout page="catalog"] выводит готовое оформление. Свои блоки можно добавлять до/после него. Политику редактировать как обычную страницу.

Тема создаёт отсутствующие страницы home, catalog, about, gallery, documents, reviews, contacts, privacy. Одноимённые существующие страницы не изменяет. Если home уже была, главную выбрать самостоятельно в «Настройки → Чтение».

Форма по умолчанию готовит mailto письмо. Автоматическая отправка через wp_mail включается в «НЛ — Контент» после согласования политики, настройки SMTP/почты хостинга и проверки фактической доставки.
При включении письма направляются на почту из панели контента. В форме только телефон и отдельное согласие. Есть проверка nonce, скрытое поле против ботов и ограничение частоты запросов.

WordPress 6.6+, PHP 8.1+. Перед установкой на существующий сайт сделайте его резервную копию.
Полный документ с решениями и недостающими данными: resheniya-i-zapusk.html (поставляется отдельно в комплекте заказа).
