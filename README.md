# Неверкинский лимонад — bezalko

Многостраничный сайт производителя безалкогольных напитков. Репозиторий содержит устанавливаемую тему WordPress и безопасный экспорт для GitHub Pages. Реальные фотографии и декларации входят в исходники; неизвестные сведения отмечены как `[заполнить]`.

- Основная ветка: `main`.
- Статическая демонстрация: ветка `gh-pages`, https://kibosh13.github.io/bezalko/ .
- Главная, каталог, компания, галерея, документы, отзывы, контакты и проект политики.

## Структура

```text
wordpress/neverkinskiy-limonad/   исходники рабочей темы и необходимые ассеты
scripts/build-demo.mjs          экспорт HTML/CSS/JS из исходников темы
scripts/check-demo.mjs          проверка путей и noindex
scripts/audit-source.mjs        проверка публикуемых файлов
scripts/publish-demo.sh         обновление gh-pages обычным Git push
docs/project-brief.html        решения по брифу и подготовка запуска
```

`dist/` создаётся локально и исключён из `main`. В репозитории нет архивов, баз, `.env`, паролей, токенов, локальных зависимостей и служебных данных Sites. Каждый ассет хранится один раз в исходниках темы. Доступ к GitHub использует `gh` и системное хранилище учётных данных.

## Демонстрация

Требуется Node.js 20+; npm-пакеты для сборки не нужны.

```sh
DEMO_BASE_PATH=/bezalko/ node scripts/build-demo.mjs
DEMO_BASE_PATH=/bezalko/ node scripts/check-demo.mjs
node scripts/audit-source.mjs
```

Для локального просмотра с путями от корня:

```sh
node scripts/build-demo.mjs
python3 -m http.server 4173 --directory dist
```

В демоверсии работают страницы, фильтры, карточки и подготовка письма через почтовую программу. **Отсутствуют сервер WordPress, панель редактирования, база данных и автоматическая отправка заявок.** Форма не сохраняет номера на сервере GitHub Pages. Пользователь самостоятельно отправляет подготовленное письмо.

## Обновления

Редактируйте файлы в `wordpress/neverkinskiy-limonad/`, проверьте изменения, коммитьте и отправляйте `main`, затем запустите:

```sh
bash scripts/publish-demo.sh
```

Скрипт сохраняет историю `gh-pages`, не применяет force push и создаёт коммит только при изменениях. Большие ZIP-архивы не используются. После push публикацию нужно проверить в GitHub Pages. При переименовании репозитория обновите `DEMO_BASE_PATH`.

## Индексация

Экспорт всегда добавляет `noindex,nofollow,noarchive` во все HTML, включая 404. `robots.txt` включён как дополнительный файл, но на GitHub Pages для проекта роботами управляет файл в корне домена; основной запрет здесь — метатег `noindex`. Это запрет индексации для соблюдающих его поисковиков, а не ограничение доступа: демонстрация публична.

В PHP рабочей темы нет принудительного `noindex`. На боевом WordPress после заполнения контента откройте «Настройки → Чтение» и снимите «Попросить поисковые системы не индексировать сайт». Если установлен SEO-плагин, также проверьте его настройки и robots.txt. Политику демоверсии нельзя переносить на боевой сайт.

## Рабочий WordPress

Установите WordPress 6.6+ / PHP 8.1+. Скопируйте `wordpress/neverkinskiy-limonad` в `wp-content/themes/` и активируйте тему. Тема создаёт отсутствующие страницы, не перезаписывает существующие. Сохраните постоянные ссылки «Название записи»; выберите страницу «Главная» в настройках чтения.

Панель «НЛ — Контент» позволяет менять тексты, контакты, шесть карточек напитков и фото из медиатеки. Страницы доступны в стандартном редакторе; шорткод `[nl_layout page="catalog"]` выводит оформленный раздел. Проект политики — обычная редактируемая страница.

Автоматическая форма выключена по умолчанию. Перед включением заполните политику и сведения `[заполнить]`, настройте SMTP/доставку почты и проверьте реальное получение заявки. Успех `wp_mail` означает приём почтовым сервисом, а не подтверждённую доставку.
