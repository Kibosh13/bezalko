# Неверкинский лимонад — bezalko

Многостраничный сайт производителя безалкогольных напитков. Боевой сайт работает на PHP с собственной панелью управления. Репозиторий также сохраняет исходные шаблоны темы WordPress и безопасный экспорт для GitHub Pages. Реальные фотографии и декларации входят в исходники; неизвестные сведения отмечены как `[заполнить]`.

- Основная ветка: `main`.
- Статическая демонстрация: ветка `gh-pages`, https://kibosh13.github.io/bezalko/ .
- Главная, каталог, компания, галерея, документы, отзывы, контакты и проект политики.

## Структура

```text
wordpress/neverkinskiy-limonad/   исходники рабочей темы и необходимые ассеты
scripts/build-demo.mjs          экспорт HTML/CSS/JS из исходников темы
scripts/build-gallery.mjs       галерея из проверенного списка фотографий
scripts/build-catalog.mjs       каталог и подборка главной из products.json
scripts/check-demo.mjs          проверка путей и noindex
scripts/audit-source.mjs        проверка публикуемых файлов
scripts/publish-demo.sh         обновление gh-pages обычным Git push
docs/project-brief.html        решения по брифу и подготовка запуска
```

`dist/` создаётся локально и исключён из `main`. В репозитории нет архивов, баз, `.env`, паролей, токенов, локальных зависимостей и служебных данных Sites. Каждый ассет хранится один раз в исходниках темы. Доступ к GitHub использует `gh` и системное хранилище учётных данных.

## Демонстрация

Требуется Node.js 20+; npm-пакеты для сборки не нужны.

```sh
DEMO_BASE_PATH=/bezalko/ node scripts/build-demo.mjs
DEMO_BASE_PATH=/bezalko/ node scripts/check-demo.mjs
node scripts/audit-source.mjs
```

Для локального просмотра с путями от корня:

```sh
node scripts/build-demo.mjs
python3 -m http.server 4173 --directory dist
```

В демоверсии работают страницы, фильтры, карточки и подготовка письма через почтовую программу. **Отсутствуют сервер WordPress, панель редактирования, база данных и автоматическая отправка заявок.** Форма не сохраняет номера на сервере GitHub Pages. Пользователь самостоятельно отправляет подготовленное письмо.

## Обновления

Редактируйте файлы в `wordpress/neverkinskiy-limonad/`, проверьте изменения, коммитьте и отправляйте `main`, затем запустите:

```sh
bash scripts/publish-demo.sh
```

Скрипт сохраняет историю `gh-pages`, не применяет force push и создаёт коммит только при изменениях. Большие ZIP-архивы не используются. После push публикацию нужно проверить в GitHub Pages. При переименовании репозитория обновите `DEMO_BASE_PATH`.

## Индексация

Экспорт всегда добавляет `noindex,nofollow,noarchive` во все HTML, включая 404. `robots.txt` включён как дополнительный файл, но на GitHub Pages для проекта роботами управляет файл в корне домена; основной запрет здесь — метатег `noindex`. Это запрет индексации для соблюдающих его поисковиков, а не ограничение доступа: демонстрация публична.

В боевой PHP-версии индексация включена в «Настройках сайта»; robots.txt, sitemap.xml, canonical и Open Graph формируются автоматически. Админка всегда закрыта от индексации. Следующие указания относятся только к сохранённой альтернативной теме WordPress. В PHP рабочей темы нет принудительного `noindex`. На боевом WordPress после заполнения контента откройте «Настройки → Чтение» и снимите «Попросить поисковые системы не индексировать сайт». Если установлен SEO-плагин, также проверьте его настройки и robots.txt. Политику демоверсии нельзя переносить на боевой сайт.

## Рабочий WordPress

Установите WordPress 6.6+ / PHP 8.1+. Скопируйте `wordpress/neverkinskiy-limonad` в `wp-content/themes/` и активируйте тему. Тема создаёт отсутствующие страницы, не перезаписывает существующие. Сохраните постоянные ссылки «Название записи»; выберите страницу «Главная» в настройках чтения.

Панель «НЛ — Контент» позволяет менять тексты, контакты, шесть карточек напитков и фото из медиатеки. Страницы доступны в стандартном редакторе; шорткод `[nl_layout page="catalog"]` выводит оформленный раздел. Проект политики — обычная редактируемая страница.

Автоматическая форма выключена по умолчанию. Перед включением заполните политику и сведения `[заполнить]`, настройте SMTP/доставку почты и проверьте реальное получение заявки. Успех `wp_mail` означает приём почтовым сервисом, а не подтверждённую доставку.

Полный список решений и недостающих данных: [бриф и запуск](docs/project-brief.html).

Материалы от 13.10.2026: [видео, отзывы, фото и карточка «Байкал»](docs/client-materials-2026-10-13.html). Видео открывается по предоставленной ссылке в VK; неподтверждённые тексты отзывов не переносились.

## Боевой сайт и собственная админка

Боевой домен: https://neverlimonad.ru/ . Панель: `/admin/`. Исходники движка находятся в `production/`, подготовка — `scripts/build-production.mjs`. WordPress для этой версии не требуется.

Требования: PHP 8.2+ с DOM, mbstring, fileinfo и PDO SQLite, Apache mod_rewrite, HTTPS. Зависимостей npm и Composer нет.

```sh
node scripts/build-production.mjs
python3 scripts/check-production.py
```

Сборка создаёт `build/production/`. В ней нет пользователей, паролей или рабочей базы. При первом размещении `cms/install.php` запускается только из CLI с SHA-256 случайного одноразового ключа. Владелец создаёт логин и пароль через ссылку с ключом в URL-фрагменте; ключ не передаётся в access-логе. Срок ссылки — 7 дней, после настройки первого пользователя она удаляется. Не передавайте ключ в репозиторий.

Данные, хеши паролей, сессии и история хранятся в соседнем с публичным каталогом `.neverlimonad-data/` (права 0700; база 0600). Загрузки находятся в `uploads/` под случайными именами. `.htaccess` закрывает служебный код от HTTP, запрещает исполнение загруженных скриптов и просмотр каталогов.

В панели доступны:

- Тексты всех восьми страниц, шапки и подвала, форматирование, ссылки, изображения и alt.
- SEO title, description, Open Graph, публикация страниц, индивидуальный noindex.
- Порядок и видимость существующих блоков.
- Добавление, редактирование, удаление и порядок напитков, галереи и документов.
- Контакты, основной адрес, общая индексация, логотип, фотографии, видео и обложка.
- Медиатека с загрузкой фото, PDF и MP4; скрытие файлов из медиатеки обратимо и не ломает опубликованные ссылки.
- Тридцать предыдущих версий каждого раздела, восстановление и экспорт контента JSON.

Форма обращения готовит письмо в почтовой программе посетителя; серверная отправка и база заявок не включены. Недостающие сведения остаются `[заполнить]`.

При обновлении переносите только изменённые файлы PHP/JS/CSS. Не запускайте установку повторно и не заменяйте `.neverlimonad-data/` или `uploads/`. Начальные шаблоны используются только при первой установке: последующие изменения владельца в базе сохраняются. Для резервной копии нужны **оба** каталога (движок с uploads и соседний каталог данных). Экспорт JSON — копия контента без учётных данных и медиафайлов, он не заменяет полную резервную копию.

На новом домене HTTP остаётся доступным, пока Beget выпускает сертификат. Движок проверяет доступность HTTPS с проверкой имени и цепочки сертификата и после успешной проверки автоматически включает 301 на HTTPS. Проверка кэшируется вне публичного каталога. Вход и API админки требуют HTTPS с самого начала.

На данном аккаунте Beget нет Node.js, поэтому сборка выполняется локально. Скрипт `scripts/deploy-beget.sh` умеет использовать заранее подготовленный `build/production/`; исходники и подготовленная сборка размещаются вне публичного каталога. PHP для установки выбирается из `/usr/local/php-cgi/8.4/bin/php`.
